Unified Login for SendGrid Marketplace Customers
SendGrid marketplace customers can now take advantage of the Unified Login feature that lets you create a Twilio login for every individual user accessing your SendGrid account. This provides a more secure access pattern with the ability to define permissions for each user instead of a single, shared admin permission set.
When accessing your SendGrid marketplace account from one of the marketplace integrations - Microsoft Azure, Google Cloud, Heroku, or Amazon Web Services - you will be prompted to provide an email address to create your Twilio login. If you already use another Twilio product and have an existing Twilio login, you can use that email address and password for SendGrid access.
This will be rolled out over the next couple weeks for all SendGrid marketplace customers. For more details, see the documentation here .

Twilio Email
Twilio Cohorts for Native List Building and Bulk Messaging
Twilio Cohorts is now available in Private Beta, providing a set of APIs designed to handle list building, audience segmentation, and bulk execution natively within the Twilio platform. Set up your customer profiles, segment them, and trigger messages using your existing Twilio account.
Twilio Cohorts includes:
Dynamic List Building & Segmentation: Define customer traits and query dynamic audiences directly within Twilio.
Native High-Volume Delivery: Pass a single CohortID when triggering a send with the Twilio Email API or the Twilio Bulk Messaging API (supporting Email, SMS/MMS, RCS, and WhatsApp) without writing custom batching logic.
Unified Execution: Streamline multi-channel workflows and eliminate custom queuing or backend rate-limiting logic.
Coordinating high-volume delivery across Email, SMS, RCS, and WhatsApp alongside your native Twilio data has never been easier.
To request early access to the Private Beta, submit a request form . For API details and technical guidance, see the Twilio Cohorts documentation .

Oct 09, 2026
GA
Voice API
Voice Insights now tags HD audio calls
Voice Insights now tags calls as HD Audio when they connect with the AMR-WB or Opus codec.
Use the tag to confirm your endpoints negotiated what you configured, and to correlate HD usage with transcription accuracy, AI agent performance, and customer satisfaction.
Calls that carry HD audio are tagged as Downsampled when the longest portion of the call connects to a component or another endpoint that does not support HD. Twilio converts the audio to narrowband to keep the call connected.
Both tags appear in the Call Summary in Console, in the Voice Insights REST API, and through Event Streams. You can also filter the Call Insights dashboard by either one.
Learn more in our Call Summary documentation .
